## Regression Red Flags

Regressions are a tool that can be used to find the casual factors of a particular variable.
They are often used when there is noisy data.

But there are problems.

In this post I'm going to highlight how regressions can give issues by using an example where the answer is arleady known, but using regressions can give wrong answers.
Furthermore it will show that it is difficult to know if you have gotten all the right answers or if there are issues.

### Nutrition 

My example is using a dataset of food to determine the kJ/g of certain components of macro nutrients. This is arleady known, but this example shows how using regressions can lead to the wrong answers.
